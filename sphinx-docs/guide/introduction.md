# Introduction

This manual is both a user guide and a reference guide for SuperBASIC: an
easy-to-use, beginner-friendly yet powerful programming language for the
Wildbits and Foenix F256 series of personal computers.

You do not need prior familiarity with the Wildbits platform to use this manual.
However, it is not intended to teach programming from scratch, and assumes some
prior knowledge of programming in general and BASIC in particular. If you're
looking for an introductory BASIC book, we highly recommend *Simple BASIC* by
Gaby Waters, which is freely available for download from Usborne's website.

SuperBASIC builds on the heritage of classic BASIC dialects while introducing
enhancements that make programming more expressive, accessible, and fun. It is
tightly integrated with the hardware capabilities of the Wildbits platform,
offering first-class access to graphics, sprites, game controllers, sound, and
more. Notable language additions include structured control flow, procedures and
functions, inline assembly, and an enriched standard library.

We've worked hard to make SuperBASIC a powerful and approachable language for
curious minds of all ages. We hope you enjoy using it as much as we enjoyed
creating it!
