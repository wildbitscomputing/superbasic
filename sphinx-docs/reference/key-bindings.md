# Key bindings / shortcuts

## Editing

| Key / shortcut                 | Action                                             |
| ------------------------------ | -------------------------------------------------- |
| {kbd}`Enter`                   | Interpret the current line                         |
| {kbd}`Shift`+{kbd}`Enter`      | Move to next line without interpreting             |
| {kbd}`Del` or {kbd}`Backspace` | Delete character before cursor                     |
| {kbd}`Ctrl`+{kbd}`D`           | Delete character at cursor                         |
| {kbd}`Ctrl`+{kbd}`K`           | Delete characters from cursor position to line end |
| {kbd}`Ins`                     | Insert a blank line                                |

## Navigation

| Key / shortcut                                  | Action                                |
| ----------------------------------------------- | ------------------------------------- |
| Arrow keys                                      | Move cursor up / down / left / right  |
| {kbd}`Ctrl`+{kbd}`Left`                         | Jump to previous word                 |
| {kbd}`Ctrl`+{kbd}`Right`                        | Jump to next word                     |
| {kbd}`Ctrl`+{kbd}`Up` or {kbd}`Ctrl`+{kbd}`A`   | Jump to beginning of line             |
| {kbd}`Ctrl`+{kbd}`Down` or {kbd}`Ctrl`+{kbd}`E` | Jump to end of line                   |
| {kbd}`Ctrl`+{kbd}`I`                            | Move cursor 8 characters to the right |

## Scrolling

| Key / shortcut         | Action                                 |
| ---------------------- | -------------------------------------- |
| {kbd}`WLD`+{kbd}`Up`   | Scroll screen up (show previous lines) |
| {kbd}`WLD`+{kbd}`Down` | Scroll screen down (show later lines)  |

## Other

| Key / shortcut                                                | Action          |
| ------------------------------------------------------------- | --------------- |
| {kbd}`Clr` ({kbd}`Shift`+{kbd}`Home`) or {kbd}`Ctrl`+{kbd}`L` | Clear screen    |
| {kbd}`Run/Stop` or {kbd}`Ctrl`+{kbd}`C`                       | Break execution |
