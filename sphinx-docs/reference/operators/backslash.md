# `\` (backward slash)

Integer division. Both operands must be integers. If the first number doesn't
divide evenly by the second, the result is the whole-number part of the answer
(rounded toward zero). An error occurs if the divisor is zero.

```basic
100 print 22 \ 7   ' prints 3
110 print -27 \ 7  ' prints -3
120 print 42 \ 7   ' prints 6
```
